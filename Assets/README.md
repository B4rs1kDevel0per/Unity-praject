# PS1 Style Pack — установка

## 1. Точечная фильтрация текстур (обязательно!)
Без этого весь эффект вертекс-снаппинга и низкого разрешения смажется билинейным сглаживанием.
Для КАЖДОЙ текстуры в проекте: Inspector -> Filter Mode -> **Point (no filter)**.
Можно один раз выставить дефолт: Edit -> Project Settings -> Player -> Default Filter Mode... но
в URP надёжнее руками проставить на текстурах — Unity иногда переопределяет через Texture Importer.

## 2. Объектный шейдер (вертекс-снаппинг + affine)
1. Импортируй `Shaders/PS1_VertexLitAffine.shader`.
2. Создай материал, Shader -> PS1Style -> VertexLitAffine.
3. `Geometry Resolution` — чем меньше число, тем сильнее "трясётся" геометрия (160 — умеренно,
   80 — очень олдскульно, 320 — почти незаметно). Подбирай на глаз под свой стиль.
4. Назначь этот материал на пропы/окружение.

## 3. Постпроцесс (дизеринг + низкое внутреннее разрешение)
1. Импортируй `Shaders/PS1_PostProcessDither.shader` и `Scripts/PS1PostProcessFeature.cs`.
2. Создай материал на основе `PS1Style/PostProcessDither`.
3. Открой свой `Universal Renderer Data` asset (Project window) -> Add Renderer Feature ->
   `PS1 Post Process Feature`.
4. В настройках фичи: `Dither Material` -> созданный материал, `Render Scale` -> начни с 0.35-0.5
   и подбирай баланс "пиксельность vs читаемость".
5. `Color Levels` в материале дизеринга — 8-16 для сильного ретро-вайба, 32+ для более чистой картинки.

## 4. Почему без FSR
Внутреннее разрешение рендера уже занижено (`Render Scale`), а апскейл на экран идёт через
Point-фильтр (см. `FilterMode.Point` в `PS1PostProcessFeature.cs`) — это одновременно и стилевой
приём (чёткие пиксельные блоки вместо мыла), и метод экономии производительности (меньше пикселей
= меньше нагрузка на фрагментный шейдер). FSR/DLSS решают обратную задачу — реконструируют резкость
из низкого разрешения, что визуально конфликтует с намеренной пиксельностью PS1-стиля.

## 5. Порядок отладки
Если картинка выглядит "слишком чисто" — сначала уменьшай `Render Scale`, потом `Color Levels`,
и только потом `Geometry Resolution` у объектов (он сильнее всего бросается в глаза, если переборщить).

## 6. Про Render Graph (Unity 6 / URP 17+)
В Unity 6 URP по умолчанию использует новый Render Graph API — старые методы `OnCameraSetup`/
`Execute` в `ScriptableRenderPass` считаются устаревшими и не переопределяются (ошибка CS0115
"no suitable method to override", если написать их вручную). `PS1PostProcessFeature.cs` уже
написан под актуальный API (`RecordRenderGraph` + `AddBlitPass`) — ничего дополнительно включать
не нужно, работает "из коробки" в Unity 6.
